# EA 用の優位性検証レポート(2026-11)

「相場を自動で判定し、優位性のあるところでエントリーする EA」を作る前に、候補となる売買ルールに**コストを差し引いても残る優位性があるか**を、実データで検証しました。

## 結論

**検証した 11 通りのルールのうち、事前に決めた採用基準を満たしたものはありませんでした。** ここで試したルールをそのまま EA にしても、長く利益を出し続けられるという根拠は得られていません。

- 2010〜2019 年でプラスに見えたもの(ドンチャン 55 日ブレイク)も、2020 年以降は大きくマイナスでした。
- 先に作ったハーモニックインジケーター(HarmonicNavi)のシグナルは、どの設定・どの期間でも 1 回あたり -0.09〜-0.25R でした。
- 言えるのは「**これらのルールには**優位性が見つからなかった」ということまでです。FX で勝てる EA が存在しないと証明したわけではありません。

## データと条件

| 項目 | 内容 |
|---|---|
| データ | HistData.com の 1 分足(BID)から作った 1 時間足・4 時間足・日足 |
| 通貨ペア | EURUSD, USDJPY, GBPUSD, AUDUSD, USDCHF, EURJPY |
| 期間 | 2010-01 〜 2026-10(約 17 年)。**前半 2010–2019 で判定し、後半 2020–2026 で確認** |
| コスト | 往復コスト(スプレッド+手数料相当)を固定で上乗せ: EURUSD 1.2 / USDJPY 1.4 / GBPUSD 1.8 / AUDUSD 1.5 / USDCHF 1.8 / EURJPY 2.0 pips |
| 約定 | 足の終値でシグナルを出し、次の足の始値で成行約定(ハーモニックだけは D での指値)。買いは ask、売りは bid |
| 判定 | 同じ足の中で損切りと利確の両方に届いた場合は、損切りを先とする(保守的) |
| 評価単位 | R(1 回の損切り額を 1 とした損益)。資金管理に左右されない比較をするため |

### 採用基準(結果を見る前に決めたもの)

- 前半: 平均 > +0.05R、PF > 1.1、6 ペア中 4 ペア以上でプラス、取引 100 回以上
- 後半: 平均 > 0、6 ペア中 4 ペア以上でプラス

時間帯アノマリーについて:
- 偏りのほとんどは往復コストより小さく、前半と後半で向きが逆になるものも多くありました。
- 21〜23 時(UTC)の大きな偏りは、日付の切り替わり時にスプレッドが広がることによる見かけ上のものです。
- EURUSD の欧州時間の下落は前半・後半とも同じ向きでしたが、後半は 0.6 pips で、コスト 1.2 pips を下回ります。

### 検証の確認と、正直に書いておくべき点

- ランダム売買の結果がコストの分だけマイナスになることを確かめ、検証エンジンが正しく動いていることを確認しました(1 時間足で -0.05〜-0.13R)。
- 「損切りを先とする」判定のため、1 時間足では 1 回あたり 0.03R 程度、不利側に偏ります。ただし不合格の理由はこの偏りより大きい差です。
- データは BID だけで、スプレッドは固定値です。実際の業者のスプレッドやスリッページとは異なります。
- EURUSD の後半の結果は、検証の試走で先に見ています。採用の判定は、前半の基準を 6 ペアにまとめて当てはめて行いました。

## 再現方法

```bash
python -m venv venv && ./venv/bin/pip install pandas numpy numba pyarrow histdata
./venv/bin/python -I research/fetch_data.py ./data EURUSD USDJPY GBPUSD AUDUSD USDCHF EURJPY   # 約 15 分
./venv/bin/python -I research/evaluate.py ./research ./data
./venv/bin/python -I research/seasonality.py ./research ./data
```

| ファイル | 役割 |

| `fetch_data.py` | HistData からの取得と足の作成 |
