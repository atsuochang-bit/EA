# HarmonicNavi (MT5 インジケーター)

ハーモニックパターン(XABCD)を検出し、**価格が D 点に届く前に**「エントリー / 損切(SL) / 利確 T1・T2・T3」をチャートに表示する MT5 用インジケーターです。D 点に届いたらシグナルとして確定させ、その後に T1/T2/T3/SL のどれに当たったかを記録して勝率表に出します。

- ファイル: `MQL5/Indicators/HarmonicNavi.mq5`
- 対応: MetaTrader 5(全シンボル・全時間足)
- 確定足だけで計算するので、**一度出たシグナルは後から消えたり動いたりしません(リペイントなし)**

## 元ネタのスクショから読み取ったこと

参考にしたのは X のポスト(@k_rsifx)の動画のスクショ 1 枚です。元のインジケーターは TradingView 用で、投稿者自身の作でもなく、コードは見ていません。このインジケーターは、スクショで**見える動き**を手がかりにゼロから書いたもので、元のコピーではありません。

| 項目 | 内容 | 確度 |
|---|---|---|
| 表示要素 | BUY/SELL ラベル(価格付き)、SL ライン(赤)、T1/T2/T3 ライン(緑)、エントリーから T1 への矢印、成績表(Target 1/2/3 hit、Timed out) | 画像で確認 |
| 利確の計算式 | **T1/T2/T3 = エントリー ± 損切幅R × 2.618 / 4.236 / 6.854**(φ², φ³, φ⁴) | BUY は表示値、SELL はライン位置から検算し、両方で一致 |
| 検出ロジック | 成績表の見出しが「…RMONIC PRO」と読め、点線のジグザグもあるので、ハーモニックパターン系と推定 | 推定 |
| 不明な点 | 正確なエントリー条件、SL の決め方、パターンの比率、時間足 | 不明 |

BUY 157.118 / SL 156.939 の場合、R = 0.179 なので、T1 = 157.118 + 0.179 × 2.618 ≈ 157.588 となり、スクショの表示値と一致します。

## 仕組み

1. **スイング検出**: 左右 `Pivot strength` 本より高い(安い)足を高値(安値)とし、交互に並ぶジグザグを作ります。`Min swing size × ATR` 未満の小さな波は無視します。
2. **パターン判定**: 直近の X-A-B-C を次の比率表と照らし合わせます(許容誤差 `Ratio tolerance`)。

   | パターン | AB/XA | BC/AB | CD/BC | D 点 | SL 基準(Pattern モード) |
   |---|---|---|---|---|---|
   | Gartley | 0.618 | 0.382–0.886 | 1.13–1.618 | XA の 0.786 | X |
   | Bat | 0.382–0.50 | 0.382–0.886 | 1.618–2.618 | XA の 0.886 | X |
   | Alt Bat | 0.236–0.382 | 0.382–0.886 | 2.0–3.618 | XA の 1.13 | XA の 1.27 |
   | Butterfly | 0.786 | 0.382–0.886 | 1.618–2.618 | XA の 1.27 | XA の 1.414 |
   | Crab | 0.382–0.618 | 0.382–0.886 | 2.24–3.618 | XA の 1.618 | XA の 2.0 |
   | Deep Crab | 0.886 | 0.382–0.886 | 2.0–3.618 | XA の 1.618 | XA の 2.0 |
   | Cypher | 0.382–0.618 | 1.13–1.414 | 1.272–2.0 | XC の 0.786 | X |

   複数のパターンが当てはまる場合は、D が一番近い(最初に到達する)ものを採用します。
3. **事前表示(待機中)**: C が確定した時点で、D(指値)、SL、T1〜T3 を点線で右側に表示し、「BUY LIMIT 157.118 Bat (waiting)」のように出します。これが「先に言ってくれる」部分です。
   - 価格が C を超えた場合、D に届く前に逆方向の波が確定した場合、`Pending setup expiry` 本を過ぎた場合は取り消します。
   - C の確定待ちの間にすでに D へ届いていた場合は、後追いになるので見送ります(成績表の `skipped(late)`)。
4. **シグナル確定**: 確定足の安値(SELL は高値)が D に届いたら、D で約定したものとして扱います。▲/▼ の矢印、BUY/SELL ラベル、各ラインを表示します。
5. **結果の追跡**: その後の足で SL と T1→T2→T3 の到達を判定します。
   - **同じ足で SL と目標の両方に届いた場合は、SL を先とみなします(保守的)**。エントリー足の中で SL に届いた場合も負けとします。
   - T3 到達、SL、または `Signal timeout` 本経過で終了します。

## インストール

1. MT5 で「ファイル → データフォルダを開く」を選びます。
2. `MQL5/Indicators/` に `HarmonicNavi.mq5` をコピーします。
3. MetaEditor でファイルを開き、「コンパイル」(F7)を押します。
4. MT5 のナビゲーターからチャートにドラッグします。

> このファイルを作った環境には MetaEditor(MQL5 コンパイラ)がなく、**v1.00 は実機でのコンパイル・表示確認をしていません**(コードを目で読んで確認しただけです)。コンパイルエラーや表示の崩れが出たら、エラーメッセージかスクショを送ってください。
>
> 制限: 同じチャートにこのインジケーターを 2 つ入れると、ライン等の図形が干渉します。1 チャートにつき 1 つで使ってください。

## 入力パラメータ

| 区分 | パラメータ | 既定値 | 説明 |
|---|---|---|---|
| スイング | Pivot strength | 5 | スイングの判定に使う左右の本数。大きいほど大きな波だけを拾います |
| | Min swing size (x ATR) | 1.0 | これより小さい波は無視(0 で無効) |
| | ATR period | 14 | ATR の期間 |
| パターン | Gartley 〜 Cypher | すべて ON | 使うパターンの選択 |
| | Ratio tolerance | 0.05 | 比率の許容誤差(5%) |
| 損切・利確 | Stop loss mode | ATR | `ATR`: D から ATR×倍率 / `Pattern`: X や拡張レベルの外側 |
| | SL distance from D (x ATR) | 1.0 | ATR モードの SL 幅 |
| | buffer beyond structure (x ATR) | 0.2 | Pattern モードで構造の外側に足す余裕 |
| | Target mode | R 倍数 | `R`: エントリー ± R×倍率(スクショと同じ方式) / `Fib`: A(C)-D 波の戻り比率 |
| | T1/T2/T3 (x R) | 2.618 / 4.236 / 6.854 | スクショから割り出した倍率 |
| | T1/T2/T3 (of A-D leg) | 0.382 / 0.618 / 1.0 | Fib モードの戻り比率 |
| | Move SL to entry after T1 | false | T1 到達後に SL を建値へ移す |
| | Pending setup expiry | 100 | 待機中のセットアップの有効本数 |
| | Signal timeout | 300 | シグナルを追跡する最大本数(超えたら Timed out) |
| 表示 | Bars to calculate | 5000 | 計算する過去の本数 |
| | Signals kept on chart | 30 | チャートに残すシグナルの数 |
| | Draw XABCD legs など | ON | 各表示の ON/OFF、成績表の位置、色、文字サイズ |
| アラート | Popup / Push | ON / OFF | ポップアップ、スマホへのプッシュ通知 |
| | Alert on new pending setup / entry / T1-T3-SL | ON | どのタイミングで通知するか |

## EA から使う(iCustom)

| バッファ | 内容 |
|---|---|
| 0 | BUY シグナル(エントリー価格)。シグナルの無い足は `EMPTY_VALUE` |
| 1 | SELL シグナル(エントリー価格) |
| 2 | SL |
| 3 / 4 / 5 | T1 / T2 / T3 |

値はシグナルが確定した足にだけ入ります。確定足だけで計算しているので、EA からは **shift = 1(直前の確定足)** を読んでください。

```mql5
int h = iCustom(_Symbol, _Period, "HarmonicNavi");
double buy[1];
if(CopyBuffer(h, 0, 1, 1, buy) == 1 && buy[0] != EMPTY_VALUE) { /* BUY シグナル */ }
```

## 成績表について(正直な注意書き)

- 成績表の数字はこのインジケーター自身が上のルールで数えたもので、**スプレッド・スリッページ・手数料を含まない**ヒット率です。損益ではありません。
- 元ポストの成績表には「T1 到達 82.6%」とありますが、元のロジックが分からないため検証できていません。
- 参考として、同じロジックを Python に移植し、実データの EURUSD 1 時間足 5000 本(2017-04〜2018-02)で既定設定のまま試した結果は次のとおりです。

  | 項目 | 結果 |
  |---|---|
  | シグナル数 | 13 |
  | T1 到達 | 3(23.1%) |
  | T2 到達 | 3(T1 の 100%) |
  | T3 到達 | 0 |
  | T1 前に SL | 10(76.9%) |

  **件数がごく少なく、通貨ペアと時間足も 1 つだけなので、良し悪しの判断材料にはなりません。** ただし、このインジケーターが「どの相場でも 8 割当たる」ものではないことは、この結果からも言えます。実際に使う前に、MT5 のストラテジーテスターや多くの通貨ペア・期間で確認してください。
